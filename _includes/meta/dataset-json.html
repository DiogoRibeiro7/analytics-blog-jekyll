{%- comment -%} --- required: - page --- schema.org/Dataset for a page in the `datasets` collection. Google Dataset Search indexes `Dataset` and nothing else, so a dataset page described only as a `WebPage` cannot be found there. Everything this needs is already in the front matter the dataset layout renders: the summary, the licence, the download and the field schema. Front matter it reads, all optional beyond the title: summary: the description; the excerpt when there is none updated: dateModified license: resolved through `page_license`, so the URL is the licence's download_url: one distribution; `distributions:` takes a list schema: name/description per field, as variableMeasured doi: identifier, as a PropertyValue and a DOI URL keywords: falls back to `tags` temporal_coverage, spatial_coverage, measurement_technique, citation is_accessible_for_free: false marks a dataset behind a wall Every field is left out when it has no value: `"license": ""` is not valid structured data, and an empty one is worse than none. {%- endcomment -%} {%- assign ds = include.page -%} {%- assign ds_url = ds.url | absolute_url -%} {%- assign ds_excerpt = ds.excerpt | strip_html | strip_newlines -%} {%- assign ds_description = ds.summary | default: ds.description | default: ds_excerpt | strip_newlines -%} {%- assign ds_license = ds | page_license -%} {%- assign ds_authors = ds | page_authors -%} {%- assign ds_keywords = ds.keywords | default: ds.tags -%} {%- comment -%} Jekyll gives a collection document without a `date:` the build time, so `page.date` cannot be trusted to mean anything. Comparing it with the build stamp tells a real publication date from that fallback, and keeps the output the same from one build to the next. {%- endcomment -%} {%- assign ds_build_stamp = site.time | date_to_xmlschema -%} {%- assign ds_published = nil -%} {%- if ds.date -%} {%- assign ds_date_stamp = ds.date | date_to_xmlschema -%} {%- unless ds_date_stamp == ds_build_stamp -%} {%- assign ds_published = ds.date -%} {%- endunless -%} {%- endif -%} {%- assign ds_modified = ds.updated | default: ds.last_modified_at | default: ds_published -%} {%- comment -%} One download, or a list of them under `distributions`. {%- endcomment -%} {%- assign ds_downloads = ds.distributions -%} {%- unless ds_downloads -%} {%- if ds.download_url -%} {%- assign ds_downloads = '' | split: '' | push: ds.download_url -%} {%- endif -%} {%- endunless -%}
