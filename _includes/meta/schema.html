{%- comment -%} --- required: - page optional: - type --- Outputs comprehensive JSON-LD metadata for the current page. Provides rich structured data for: - Article/BlogPosting/TechArticle schema for posts - WebPage schema for standard pages - Author information with social profile links - Publisher: a Person or an Organization, from `publisher` in _config.yml - Images, keywords, and content metadata Defaults to TechArticle for posts, WebPage for other pages. A dataset page adds a Dataset node, and a package page a SoftwareSourceCode node. `schema_type: ProfilePage` describes a page about a person or an organization: its `mainEntity` is the page's first author (the site's author by default), or the publisher with `main_entity: publisher`. The site's author and the publisher carry stable `@id`s under the site's root (`#person`, `#organization`), so every page names the same entities. With `site_identity` in _config.yml, the homepage also describes the site itself: a `WebSite` node (`#website`) with its name and other names, and the publisher's full node, which search engines read
