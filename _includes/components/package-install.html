{%- comment -%} Package Installation Component Installation commands for a package, one tab per registry the page names in `registry:` (pip, conda, CRAN, cargo, gem with its Gemfile line, npm, Pkg), then Git. A page that names none keeps the tabs of its language: pip, conda and Git for Python, CRAN and GitHub for R. A package with neither a registry nor a repository gets no panel, never an empty one. Parameters (all optional; the page's front matter fills them in): - language: python, r, rust, ruby, javascript, julia, ... - package_name: Name of the package (default: the page title) - pip_command, conda_command, cran_command: replace that tab's command - git_url: repository to clone (default: the page's github_url) The tabs and the copy buttons are wired by the core bundle (assets/js/core/install-tabs.js, assets/js/core/copy-buttons.js). {%- endcomment -%} {%- assign package_name = include.package_name | default: page.title -%} {%- assign tabs = page | package_install_tabs: language: include.language, name: package_name, git_url: include.git_url, pip: include.pip_command, conda: include.conda_command, cran: include.cran_command -%} {%- comment -%} The id is the package's, not "installation": a page whose Markdown has an `## Installation` heading gets that id from kramdown, and two elements shared it. {%- endcomment -%} {%- assign install_id = package_name | slugify | prepend: 'install-' -%} {%- capture copied_label %}{% t 'package_install.copied' %}{% endcapture -%} {%- capture copy_error_label %}{% t 'package_install.copy_error' %}{% endcapture -%} {%- if tabs.size > 0 -%}
