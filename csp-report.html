Content Security Policy report console

Use this page to validate that violation reports are sent correctly. Submitting the form will POST the JSON payload to /csp-report. During development the site logs received reports to the browser console via the securitypolicyviolation event listener.

Update the sample JSON before submitting or use the browser console to dispatch a SecurityPolicyViolationEvent to test live reporting.
