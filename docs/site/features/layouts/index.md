<section class="section">
  <div class="container">
    <h2>Landing page</h2>
    <p>The <strong>home</strong> layout powers the documentation front page. It renders the hero include plus recent posts and
    portfolio highlights automatically. Customize the hero copy via front matter on <code>index.md</code> and add featured
    collections by adding posts and portfolio entries.</p>
    <a class="btn" href="/">View live example</a>
  </div>
</section>

<section class="section section-alt">
  <div class="container">
    <h2>Article and changelog pages</h2>
    <p>Use the <strong>post</strong> layout for long-form updates and tutorials. Posts automatically generate reading time
    estimates, share structured data, and surface related taxonomy metadata. The <a href="/blog/introducing-datalog-theme/">introductory post</a> demonstrates callouts, tabbed code blocks, and
    timeline components.</p>
  </div>
</section>

<section class="section">
  <div class="container">
    <h2>Interactive notebooks</h2>
    <p>The <strong>notebook</strong> layout mirrors Jupyter and Colab metadata panels so readers can trust execution details.
    It supports download links, Binder/Colab integrations, and ipywidgets playback. Explore the
    <a href="/notebooks/batch-anomaly-detection/">batch anomaly detection notebook</a> to see the sidebar stats and runtime metadata in action.</p>
  </div>
</section>

<section class="section section-alt">
  <div class="container">
    <h2>Dataset catalog</h2>
    <p>Publish data dictionaries with licensing information via the <strong>dataset</strong> layout. Rich metadata lists,
    provenance notes, and related resources are rendered with zero additional markup. Review the
    <a href="/datasets/retail-demand-benchmark/">retail demand benchmark dataset</a> for a complete example.</p>
  </div>
</section>

<section class="section">
  <div class="container">
    <h2>Project and portfolio pages</h2>
    <p>The <strong>project</strong> layout powers featured case studies with project metadata, call-to-action buttons, and
    structured summaries. The <a href="/portfolio/interactive-forecasting-workbench/">interactive forecasting workbench</a>
    entry highlights how to link to repositories, dashboards, and presentation decks.</p>
  </div>
</section>

<section class="section section-alt">
  <div class="container">
    <h2>Research knowledge base</h2>
    <p>The <strong>research</strong> layout (available as <code>_layouts/research.html</code>) is ideal for academic teams that need
    to catalog publications, active collaborations, and submission timelines. See the
    <a href="/pages/research-operations/">research operations hub</a> for a fully wired instance.</p>
  </div>
</section>
